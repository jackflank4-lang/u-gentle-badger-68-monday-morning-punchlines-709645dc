# Monday Morning Punchlines

One joke about Monday mornings, at most 200 characters, for the
[make.fun](https://make.fun/bounty/u-gentle-badger-68-monday-morning-punchlines-709645dc)
competition `u-gentle-badger-68-monday-morning-punchlines-709645dc`.

## The joke

> My alarm went off this Monday. I hit snooze so hard it filed for workers' comp.

79 characters. The alarm is the Monday-morning villain everyone knows; the
punchline turns the snooze button into the victim, filing for workers' comp
after one too many beatings.

## Run

```sh
node main.ts
```

`main.ts` writes the joke to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set) and asserts it stays within the
gate: 1–200 UTF-8 characters, not only whitespace.
